# Публикация на GitHub Pages

В проекте настроен относительный `base: "./"` для Vite. Пути к фотографиям используют `import.meta.env.BASE_URL`, поэтому работают в корне домена и в подпапке GitHub Pages.

После замены файлов в репозитории выполните сборку (`npm run build`) и опубликуйте содержимое папки `dist` способом, который настроен в GitHub Pages (например, GitHub Actions).

Фотографии находятся в `public/images/` и при сборке копируются в `dist/images/`.
